# TCK-104 · Desk summary takes 12-15 seconds
**Customer:** Aldermoor Capital · **Reporter:** Luis Ortega, Platform Engineer · **Version:** 2.4.0

> `GET /api/v1/desks/RATES/summary` takes 12-15 s in PROD. Small desks are faster.
> Our DBA looked at PostgreSQL and says the database is not overloaded, but it receives
> **thousands of small, almost identical queries**. Top of `pg_stat_statements`:
>
> ```
> calls  | mean_ms | query
> -------+---------+------------------------------------------------------------------
> 48212  |   0.21  | select t1_0.book_id,t1_0.id,... from trade t1_0 where t1_0.book_id=$1
>   812  |   0.35  | select b1_0.desk_id,b1_0.id,b1_0.name from book b1_0 where b1_0.desk_id=$1
> ```
> The database has 3 ms of network latency from the application servers.

**Test:** `Tck104DeskSummarySlowTest` (counts the SQL statements executed)
